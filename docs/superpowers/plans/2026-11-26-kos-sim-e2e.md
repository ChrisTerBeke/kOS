# kOS Offline E2E Simulator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Python `sim/` package that interprets real `.ks` scripts against a pluggable Kerbin physics host and greens an `f9_test` E2E pytest in CI.

**Architecture:** Layered KerboScript runtime (lexer → parser → AST → tree-walk VM initially, bytecode-ready AST) talks only to `KosHost`; `SimHost` implements Kerbin-ish physics; harness boots archive + vehicle and asserts orbit tolerances + invariants.

**Tech Stack:** Python 3.12+, pytest, PyYAML, lark (grammar), GitHub Actions

## Global Constraints

- Python 3.12+; no KSP dependency in CI
- VM must not import `sim_host` — only `kos_host` protocols
- Unimplemented language/host features raise explicit errors (never silent)
- Real `.ks` under `programs/` remain source of truth (no port of mission logic)
- E2E: full `f9_test`; Ap/Pe ±5 km of 140 km; inclination ±2° of 25°; flight invariants
- Full KerboScript/kOS language is the runtime goal; phase builtins; stub rare host suffixes loudly
